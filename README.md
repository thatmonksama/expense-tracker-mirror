# Expense Tracker

A lightweight project for recording, reviewing, and exporting expense data.

## Overview

Expense Tracker provides a simple structure for maintaining expense records and documenting common workflows for reviewing financial data.

The repository currently contains sample data and configuration examples for demonstration and development purposes.

## Repository Structure

- `expenses.csv` - Sample expense records used for testing and demonstrations.
- `config.example.json` - Example configuration settings.
- `CONTRIBUTING.md` - Contribution guidelines.
- `CHANGELOG.md` - Project change history.
- `docs/usage.md` - Basic usage documentation.

## Data Format

Expense records use the following fields:

- `date`
- `category`
- `description`
- `amount`
- `currency`
